# Yellow Jellow's Mellow's Adventure:

This is a game about being a jello jelly and using movement to get thru levels.

## Description

Yellow Jellow's Mellow's Adventure is a game about a piece of JellO getting through platformer levels by using it's abilities to bounce back.
It uses its squish abilities, its smoosh, and many others to get through these levels.

## Help

- Press the button to start

- A,W,D are left, up, and right.
- Use J while using the <,>, or down at a wall to bounce.
- Yums are the Gelatin Packets.

- Pressing W twice quickly makes it less resistant to gravity for a set time.
- Keep on going shows 1-3 and you completed it shows when finished.
